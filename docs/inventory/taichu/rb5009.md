主路由，非 NixOS 设备。

| 项目 | 观察值 |
| --- | --- |

| CPU | ARM64，4 核 |
| 内存 / 存储 | 1 GiB / 1 GiB |

## 系统

RouterOS 7.22 stable。

## 网络位置

主路由地址 `172.16.100.254`；`inbound` 上联当前从 DHCP 获得 `172.16.20.252/24`。
`ether3` 接 2.5GbE 存储交换机，属于 `harvester-stor`；`ether4` 接 m920x，属于 `harvester-mgmt`。两口在 2026-09-23 换线后均以 1 Gbps 协商。`ether5` 接 mAP lite，属于 `auxiliary`；`ether6`、`ether7`、`ether8` 分别接机架从下往上的 `mc5-01`、`mc4-01`、`mc4-02`，属于 `harvester-mgmt`。

## 运行角色

为 Harvester 管理网、虚拟机网及存储网提供路由。存储网保留 `172.16.105.254/24`，不再由 RB5009 提供 DHCP；Longhorn 存储地址由 Harvester 的 Whereabouts 分配。设备上运行 Tailscale 容器；出口节点的当前可用状态见私有运维记录。
