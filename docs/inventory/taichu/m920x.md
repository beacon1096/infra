# ThinkCentre m920x

NixOS 驻守节点。

## 硬件信息

| 项目 | 观察值 |
| --- | --- |
| 机型 | Lenovo ThinkCentre m920x，DMI 产品号 `10S4CTO1WW` |
| BIOS | M1UKT77A（2024-04-10） |
| CPU | Intel i5-8600，6 核 6 线程 |
| 内存 | 32 GiB：2 × 16 GiB DDR4，配置速率 2666 MT/s；SMBIOS 纠错类型为 None |
| 磁盘 | KIOXIA EXCERIA G2 NVMe，约 1 TB |
| GPU | NVIDIA Tesla P4，8 GiB；2026-09-23 拆机检查后已被 NVIDIA 580.173.02 驱动识别，尚未验证推理负载 |

## 系统

NixOS；Linux 内核 `7.1.3-cachyos-lto`。`cachyos` 是内核构建标识，不是操作系统发行版。

## 网络位置

当前 `eno1` 通过 DHCP 取得管理网地址 `172.16.100.250/24`；Tailscale `100.101.83.77`。此前误接存储网时取得过 `172.16.105.248/24`；`172.16.100.250` 同时是 BIRD 的路由器 ID。

## 运行角色

太初网络的 NixOS 驻守节点，配置了 BIRD OSPF 出口通告；邻接当前运行状态见私有运维记录。

## 私有运维信息

SSH 与 Intel AMT 的访问方式见私有仓 `infra-private/docs/inventory/taichu/m920x.md`。
